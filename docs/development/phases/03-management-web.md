# 03 管理界面原型落地

## 目标与范围

按 R-18～R-21 将已认可原型迁移到 daemon 托管的真实 Web。本单元是完整管理体验的一次可运行切片，不把缺失的 MCP/隧道后端和可信当前浏览器自动识别改写成已完成。

输入：[Web 设计](../../design/web.md)、[连接合同](../../design/browser-connection.md)、已批准的 `avru-console-preview` 原型。实现基线 `44c371a725ce703ceb437bd6aaa78c910ecbb1b8`。

### 明确保留的缺口

- npm 开发包尚不含可加载扩展，尚未完成稳定目录分发与更新事务；安装引导必须如实报告，而不是生成一个不存在的目录。
- 当前浏览器无核对码可信握手尚未完成，保留已有人工核对批准，避免为 UI 自动跳转放松认证。
- 当前扩展弹窗仍承担配对，不能把后台纯插件/点击统一 Web 目标记成已完成。
- MCP/OAuth、ChatGPT/FRPC配置执行、QuickJS控制及Trace采集后端仍待实现；界面只可显示明确空状态，不算完整 R-21 验收。
- 自动品牌浏览器全矩阵、真实 OS 登录仍未验收。现有 Chromium E2E 不代表所有品牌和用户机器。
