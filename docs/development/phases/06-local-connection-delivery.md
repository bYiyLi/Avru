# 五项本机交付与 npm 开发版

## 本轮批准范围

依据 2026-11-08 用户批准的五项计划，承接 `4bee8df` 及现有未提交持久调用记录。完成现有只读浏览器能力的日志、插件安装连接、双环境隔离、npm dev 发行，以及内嵌 FRPC 与本机自动连接管理。SDK 与网页动作另行设计。

用户只导入配置，由 Avru 自动管理连接。内嵌 FRPC v0.72.0 四平台资产，仅做来源、归档/程序摘要、架构和许可静态校验；测试执行替身进程和模拟管理 API，不运行官方 FRPC（含 --version/verify）。不部署 FRPS、不访问公网隧道或真实 ChatGPT。平台采用 Mac 真机与 Windows CI；Windows 实机不在本轮验收。Mac 最终保留 dev，prod 本地验收程序与登录项在验收后移除。

## 交付与验收

- SQLite：MCP 最近 200 条，连接活动独立 200 条；重启回读、未知结果、容量、事务失败和脱敏。
- 插件：实际包中稳定目录、免短码连接、双浏览器/配置、重启、撤销和升级重新加载。
- 隔离：真实编译身份的 private dev/prod 包、独立状态/进程/凭据/登录项、升级与目标卸载。
- 连接：配置白名单及证书验证、本机受保护 API、原子保存、当前用户文件权限、自动生命周期、私密实例恢复及未知归属拒绝。
- npm：同一份 tgz 的 Win/Mac 门禁、安装与真实浏览器回归；冻结源提交、run、artifact、摘要，取得精确候选的最终发布批准；发布后回读 registry 并验证下载包。

设计真源见 [MCP](../../design/mcp.md)、[安装](../../design/installation.md)和[环境](../../design/environments.md)。安装说明见[连接导入](../../guide/connection.md)，候选与公开流程见[发行](../../guide/release.md)。
