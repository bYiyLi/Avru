# 安装与卸载操作说明

当前仅适用于从源码构建的 artifacts/avru bundle；正式 npm 包尚未发布，以下 avru/npx 名称说明目标命令，不保证 registry 可安装。实现来源为 apps/cli/src/main.ts、flow.ts 与 install.ts。

目标公开入口为 `npx -y avru`；在正式发布前不能据此声称用户已可从 npm 安装。`-y` 是 npm 下载确认，不是 Avru 删除数据确认。Avru 交互终端展示影响并确认；无人值守必须显式 `--yes`。

- `avru`：显示当前环境和安装状态。首次安装前确认；同版本可打开管理页、修复或退出；较新安装包需确认更新，较旧安装包不自动降级。
- `avru uninstall`：选择卸载并保留数据、卸载并清除已知 Avru 数据或取消；清除时再次显示范围并确认。
- `avru uninstall --yes --remove-data`：明确删除已知配对与记录数据库、连接配置及凭据，不递归删除用户自建文件。
- `--help` / `--version`：只读，不启动或安装。

支持 Windows/macOS；Linux 明确拒绝安装。Node 24.22.1 至 24.x 由用户提供，程序记录绝对 Node 路径；删除或搬动 Node 后需重跑安装修复。用户不需要安装 pnpm。

## 执行前与故障处理

安装会写当前用户 Avru 稳定目录、启动 daemon 并注册登录入口；卸载会停止服务和删除程序。不要把数据目录指向其他应用或使用符号链接。删除配对数据会失去连接身份；未明确选择时保留。运行前先 `--help` 查看该 bundle 支持参数。

安装失败时查看实际报错，未知旧进程或归属冲突先停止，不反复覆盖。浏览器打开失败而服务健康时使用 CLI 给出的本机私密链接；不可分享。崩溃残留锁需先确认没有安装进程，不能自动抢占。Node 路径失效后恢复支持的 Node，再重跑安装修复。具体目录、认证关闭、回滚和登录边界见[安装设计](../design/installation.md)。

验收覆盖和未执行项见[安装阶段](../development/phases/02-installer.md)；本指南不宣称已在用户机器执行。

## 输出、参数与退出状态

当前 bundle `--help` 显示 `avru [--yes] | avru uninstall [--yes] [--remove-data]`；`--version` 显示实际编译版本（开发版为 `0.1.0-dev.1`）。不支持的参数、非交互未给 `--yes`、安装/卸载失败以及非 Windows/macOS 安装均返回 1；正常完成或交互取消返回 0，取消会明确输出“未作更改”，不能仅凭退出码判断已安装。`--remove-data` 只与卸载搭配；`--yes` 不自动代表删数据。

环境：`AVRU_DATA_DIR` 可指定专用私有数据目录；`AVRU_PACKAGE_ROOT` 用于开发测试定位 bundle，不作为终端用户配置流程。Node 绝对路径被记录，移动 Node 后须修复。实际自启动文件与回滚细节只在安装设计维护。

## 在当前浏览器加载本地扩展

安装器准备的是预构建文件，不会替你点击浏览器的安装确认。完成安装后打开 CLI 提供的本机管理页，在“安装扩展”查看此安装实例返回的实际目录。默认位于个人目录的 Avru 文件夹：macOS 为 `~/Avru/dev/extension`，Windows 为 `%USERPROFILE%\Avru\dev\extension`；正式环境为 `prod/extension`。可在访达/文件资源管理器进入个人目录 → Avru → dev → extension。自定义数据根以页面实际路径为准，不选择 npx 缓存或源码目录。

1. 欢迎页点击“进入 Avru”进入管理页面，需要安装插件时再选择“安装扩展”。手册不探测浏览器或安装状态。
2. 用户在 Chrome 地址栏打开 `chrome://extensions`，或在 Edge 打开 `edge://extensions`；开启开发者模式，选择加载解压缩的扩展。
3. 选择对应环境的稳定插件目录。默认在个人目录的 Avru 文件夹下：开发版为 `dev/extension`，正式版为 `prod/extension`；自定义安装时使用该安装目录下的 extension。页面取得实际目录时也会显示它。
4. 加载后插件在后台自动连接本机服务，无需配对、核对码或批准。点击插件工具栏图标直接进入管理页面。浏览器或服务重启后会自动恢复；需要停止该浏览器连接时，在浏览器中禁用或移除插件。

管理页面可直接用本机地址打开，不需复制凭据。无法取得实际状态时显示暂不可用，不据此判断未安装或要求重新安装。

选择更新或重新修复时，安装器会更新相同环境的稳定目录。完成后如浏览器仍运行旧扩展，可在浏览器扩展管理页对 Avru 点击重新加载，再核对总览中的运行版本；只看到新文件版本并不代表浏览器已更新。仅打开管理页面不会替换程序或插件文件。另一个环境的扩展、数据和连接不应变化。

卸载 Avru 后浏览器的扩展记录不会被程序移除，稳定扩展目录及备份保留。请先在浏览器移除 Avru，再按需要删除该环境的 extension 目录及备份；不要删除另一环境或自建文件。默认保留配对数据库和连接配置；`--remove-data` 删除 SQLite 及明确列出的 Avru 自有连接凭据和运行文件，详见[安装合同](../design/installation.md)。用户原始导入文件不由卸载器删除。

安装包还携带连接组件，用户通过[导入连接文件](connection.md)交给 Avru 自动管理，无需操作 FRPC。当前实现及本轮验收不代表真实公网或 ChatGPT 已连接。

本机连接不要求保持安装手册打开，也不根据页面探测结果决定是否允许安装。管理页只展示服务实际报告的状态；本机连接成功不代表已完成 ChatGPT/FRPC 或远程 OAuth 配置。
