# 本地管理 Web

本文件拥有人的管理交互；daemon 仍拥有授权决定。当前合同依据 R-18～R-21 和 S-17～S-20，替代 S-16 的旧单页范围。视觉参考为私有 `avru-console-preview` 原型，不把原型模拟数据当作实际运行结果。

## 三页与职责

1. **欢迎**：每次进入先显示欢迎页，维持绿色品牌与留白；不在首屏塞管理表格。继续设置后才判断当前浏览器连接。
2. **安装与连接引导**：只针对当前浏览器配置进行本地扩展安装与连接引导。浏览器名称提示可以来自 UA，但不能据此推断是否安装扩展。Chrome/Edge 采用开发者模式与“加载已解压的扩展”；不能静默安装或把普通页面按钮伪装成能直接打开浏览器受限管理页面。复制管理地址、复制真实稳定扩展目录与安装后复查属于目标体验。
3. **系统总览**：展示整个 Avru，含守护进程、已配对/在线浏览器和标签、连接方式及调用观测。当前浏览器仅可作为列表附加标识，不能用它替代全系统状态。使用连续行、表格和分隔线，不采用大型卡片堆叠。

主题通过 `prefers-color-scheme` 跟随系统；语言按浏览器首选语言，以 `zh` 开头使用中文，其余英文，不提供主题或语言切换。系统浏览器语言是 Web 可访问的信号，不假称可以读取宿主 OS 的独立语言设置。窄屏保留信息与操作可达性，不把横向溢出当响应式布局。

## 真实状态与版本

- 页面打开、会话授权、daemon 连接、扩展安装、扩展配对和 MCP 可用性分别表达。请求失败清除旧在线数据显示，不保留绿色假在线。
- 版本信息来自已认证扩展连接的元数据，不能从管理页面的 UA 填充其他浏览器。User-Agent 降精度时标明来源限制；未上报和离线均显示未知。
- 插件一致性比较 `extensionVersion` 与 daemon 声明的 `expectedExtensionVersion`；浏览器自身版本不是比较目标。一致只说明版本相同，不证明授权、能力或健康。
- 管理接口与扩展协议由[浏览器连接合同](browser-connection.md)拥有。元数据不增加权限，不改变凭据和配对机制。

## 配对与当前浏览器识别边界

同一标签页重新打开完整私密管理链接时，合法的新 `#key=` capability 触发页面重载，由既有初始化读取并立即移除 fragment；不把旧会话复用为新授权。无关或格式错误的 fragment 不触发重载。

当前安全基线仍为扩展弹窗发起、管理页核对六位码批准，原连接接收凭据。不能因取消手填短码的 UI 目标而让任意扩展 Origin 自动获准。

新 Web 不用另一个浏览器在线来判定当前浏览器已安装；可信当前配置握手未完成前，明确显示无法判断并提供安装、启用、隐私模式排查及“查看系统总览”入口。浏览器/配置自动匹配以及无核对码身份绑定需要另行完成可验证的一次性凭据与来源绑定合同，不能用前端猜测替代。

## 连接方式与链路观测

ChatGPT 通道及 FRPC 是两个连接配置入口；只有真实支持的后端才能保存、测试连接或声称可用。当前未实现时只展示说明和状态，不保存虚假配置、生成假的 MCP URL 或要求用户提交秘密。

最终 MCP 详情要求实际 Trace ID、Request ID、Span/Parent、逐步骤时间/耗时、结果和关联脱敏日志；未知结果不能归为失败，更不能盲重放。没有执行记录源时展示明确空状态，不用示例日志填充产品。严禁日志包含 bearer、配对凭据、cookie、完整参数、私密页面内容及带秘密的 URL。

## 实施与发布边界

实施范围、验收及缺口见[管理界面阶段](../development/phases/03-management-web.md)。本次迁移不宣称已实现受控 SDK、远程 MCP/OAuth、ChatGPT/FRPC、扩展自动安装、当前浏览器可信握手或完整链路采集。开发包是否携带可加载扩展必须以发行清单核验，不能提供不存在的稳定目录。
