# 安装与运行生命周期

对应 R-11–R-14、D-08/D-09。CLI 拥有程序生命周期，Web 拥有后续配置；本文件拥有当前实现合同。安装包未发布，真实 OS 登录触发仍未验收，状态见[安装阶段](../development/phases/02-installer.md)。

## 目录、事务与恢复

数据根按[dev/prod环境合同](environments.md)选择；原`~/.avru`仅为拒绝自动采用的旧版根。各环境根内：`browsers.sqlite` 为配对数据；`program/releases/<uuid>` 保存完整 bundle 与 Web；`program/active.json` 原子切换当前版本；`program/launcher.mjs` 为稳定登录入口。daemon 不依赖 npx 缓存。`runtime.json` 保存当前实例与私密管理链接，权限 0600；日志同样私有，不能将原始日志或链接贴到公开报告。

安装持有 `.install.lock` 排他锁，拒绝未知 program 归属及符号链接。候选完整后停止旧实例，再切换指针、启动并认证就绪，然后配置登录入口。失败恢复旧指针并重启旧实例；停止失败时不删除可能仍在使用的版本。旧 release 暂保留，不自动清理或迁移用户数据。崩溃遗留锁不自动抢占，先确认没有安装进程再人工处理，不能盲重试。浏览器打开失败不会回滚健康实例，而是给出本机私密链接。

runtime 描述符中的 PID 不是杀进程依据。CLI 验证 loopback 地址、管理 capability 和随机实例，再请求认证关机并等待描述符消失；不对旧 PID 发送信号，未知结果停止更新并报错。

## 登录启动

macOS 写用户 `~/Library/LaunchAgents/ai.avru.daemon.<channel>.plist`，Windows 写用户 Startup `Avru-<channel>.cmd`，支持 APPDATA 重定向。只改 Avru 标记文件，拒绝覆盖外部文件。不是系统级服务，不需要管理员，不承诺登录前运行；当前启动由 CLI 完成，下一次登录由 OS 触发。macOS launcher 在 launchd 所属进程加载当前 daemon，不提前退出后遗留子进程；Windows launcher 启动后台子进程后退出。Windows 命令窗口可能短暂出现。关闭管理页不停止 daemon。

这是受当前 OS 用户保护的本机边界，不抵抗同用户恶意程序。macOS/Windows 文件权限和登录策略差异需实际机器验收，不能从 Unix mode 推断 Windows ACL。

登录入口从自身稳定路径推导数据根，不依赖临时 npx 环境变量。launcher 随 release 保存，切换失败恢复旧版本 launcher；注册失败原子撤销本次 launcher 替换。

QuickJS WASM/FRPC 尚未随 bundle 交付；今后纳入安装事务需要对应资产和版本验证。软件版本来自此次 npx 解析的包，npm 发布、包名归属、签名/公证、最终平台架构矩阵和未来数据迁移仍未解决。

## 一般运行恢复约束

| 情况                         | 建议行为                                                                                                                                     |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| 扩展未安装或浏览器未启动     | 显示未连接；不反复启动或控制别的浏览器                                                                                                       |
| 扩展/浏览器重连              | 重新注册连接代次、刷新标签页；旧目标引用需重新解析                                                                                           |
| 守护进程崩溃或电脑重新登录   | 由受控自启动机制恢复；重新核对配置、授权与连接，不重放未知副作用                                                                             |
| 电脑休眠、用户退出、网络中断 | 明确离线；恢复后重新握手，不承诺后台继续操作                                                                                                 |
| FRP 隧道断开                 | 远程能力不可用；本机状态可保留，是否有离线控制入口未定                                                                                       |
| 用户拒绝/取消/超时授权       | 不签发有效 grant；清理待确认状态                                                                                                             |
| 撤销授权与请求同时发生       | 执行前再次核对；未执行请求拒绝，已经发生的网页副作用不能保证撤销                                                                             |
| 用户停止控制                 | 停止新的操作并尽力取消未开始请求；报告已执行部分，不谎称业务回滚                                                                             |
| 安装或升级部分失败           | 显示实际完成步骤与剩余状态；现有安装事务按上文恢复；未来 FRPC/runner 和迁移仍须单独设计                                                      |
| 卸载                         | 按 R-14 停止守护进程、移除自启动与程序，并让用户选择保留或删除配置数据；FRPC、安装身份、授权记录及凭据的具体清理范围与失败恢复仍需 Q-06 细化 |

本机程序回滚与清理以本文件当前合同为准；远程组件与凭据迁移不由现有实现代替。

## 私有测试包构建边界

开发测试发行由[发行指南](../guide/release.md)定义。`0.1.0-dev.1` 构建包含 CLI、daemon、Web 及下述预构建扩展；本地候选 `private:true` 阻止误发 npm，公开 dev 发布另走发行流程。MCP 目前只有只读授权阶段，不含完整浏览器操作、FRPC 或 QuickJS。项目源仓库和编译分发物分别控制，编译 JS 仍可被分析，不承诺绝对保密。

构建仅在本机使用精确锁定的 `javascript-obfuscator@4.1.1` 同步 API；只变换 `apps/daemon/src/http-security.ts`，第三方代码、CLI、Web、扩展不进行混淆。禁用全局/属性重命名、控制流平坦化、反调试、控制台抑制、自防护与 source map；其余 bundle 常规压缩。无云 API、网络混淆或源码上传。依赖安装禁生命周期脚本，只有既有批准的 esbuild/WXT准备显式运行。

包校验按文件白名单拒绝源码/映射/未知文件、源码路径与部分高风险秘密格式，逐包收集实际 bundle 依赖许可正文；这些检查不是穷尽秘密检测或防逆向保证。缺许可则失败，不能为完成打包删除第三方版权；上游缺许可文件的精确版本采用来源及 hash 固定的官方许可副本，不改变 Avru 自有代码的授权。

## 随包扩展的稳定交付

安装 payload 同时包含当前 channel 的 WXT 预构建 `extension/`；用户不需要源码、pnpm 或 WXT。CLI 在停止旧服务前验证 MV3 清单和 manifest 公钥导出的固定 channel ID，将文件暂存到目标环境根，再以目录重命名切换到 `<dataRoot>/extension`。它不在 npx 缓存或 release UUID 路径内，不依赖符号链接。公钥和 ID 只验证预期构建身份，不代替连接凭据或供应链签名。

更新与程序激活共同回滚：停止失败不切换扩展；启动/自启动失败且确认候选进程停止后恢复旧目录与程序指针；不能确认进程退出时保留现场，不删除可能使用中的文件。成功更新暂保留 `.extension-backup-<uuid>` 旧目录作恢复材料，与已有 release 保留策略一致；崩溃遗留锁仍要求确认进程状态后人工恢复，不自动抢锁。原目录未知归属、符号链接或错误环境身份均拒绝覆盖。

`GET /api/status.extensionFiles` 在 daemon 启动时检查实际安装目录与归属、manifest/channel，返回 `{directory,version,extensionId}` 或 null；仅受本机管理 capability 保护。此结果是已准备的磁盘文件快照，不是插件已安装/启用/重新加载的证据。浏览器实际运行的插件版本仍来自认证连接元数据；升级后需用户在浏览器扩展管理页点击重新加载，不能将磁盘替换描述成已热更新浏览器。浏览器版本不用于授权判断。

卸载停止服务并移除 program/登录项，保留稳定 extension 目录和其备份。原因是浏览器管理其已加载记录，本程序不能假装移除该记录；用户先从各浏览器移除扩展后可自行删除保留目录。`--remove-data`仍只覆盖原有明确 SQLite 文件，不扩展到任意用户文件。重新安装同环境可重用受标记保护的目录。首次免短码配对尚未交付，现有安全核对批准不因安装体验而删除。
