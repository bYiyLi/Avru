# Avru

Avru 是一个独立的浏览器控制项目：让 ChatGPT 等 AI 通过 MCP，操作用户电脑上已经打开的浏览器与标签页。

## 当前状态

本仓库已实现第一阶段本机连接：Fastify daemon 托管管理 Web，Chromium MV3 扩展经管理页批准配对，同步多个浏览器配置的普通网页标签并在断线后恢复。实现与验证范围见[本机连接记录](docs/development/browser-connection.md)。Clack 安装/修复/卸载与登录启动实现见[安装设计](docs/development/installer.md)，实际跨平台验收状态单独记录。MCP/OAuth、网页操作、QuickJS 执行器尚未实现；未发布 npm 包或浏览器扩展，不代表完整产品验收。

项目名称已确定为 **Avru**。仓库名不代表 npm 包名、域名或商标已取得。

## 已确认的方向

- 扩展工程使用 WXT + TypeScript，开发包管理使用 pnpm；用户仍使用 npx 入口，无需安装 pnpm。开发依赖已固定并提交锁文件；当前验证范围见初始化记录。
- 自定义浏览器扩展通过本机 WebSocket 连接守护进程，使用 CDP / 浏览器扩展 API 控制网页；不默认开放远程调试端口。
- AI 通过受控浏览器 SDK 脚本请求操作；QuickJS 运行于单个独立、可复用进程，实际权限和目标校验由守护进程负责。
- 多个已连接浏览器共用一个本机守护进程。
- AI 可以看到所有已连接浏览器的标签页，并按任务自行选择目标，不要求用户先手动选择浏览器或标签页。
- 对外通过 MCP 提供能力，使用 MCP OAuth；FRPC/FRPS 提供内网穿透链路。
- 授权确认必须在目标守护进程所在电脑完成，允许通过远程桌面操作这台电脑。
- 用户不需要记、复制或填写 token；必要的内部凭据由系统管理。
- 用户自备 Node.js/npm，以 `npx -y avru` 为入口，支持 Windows 和 macOS。首次运行安装 Avru、配置用户登录后自启动、启动守护进程并打开本地管理 Web。
- 再次运行同一命令检查并更新 Avru、保留已有设置，确保守护进程启动并打开本地管理 Web。
- 使用 `npx -y avru uninstall` 停止守护进程、移除自启动和程序文件；配置与数据由用户在卸载时选择保留或删除。
- 浏览器选择、扩展安装引导、连接配置与运行状态由守护进程提供的本地 Web 承担；扩展安装仍需用户在浏览器中确认，不静默安装。

## 开发入口（不是终端用户安装流程）

先准备 Node.js 24.22.1 与 pnpm 11.25.0，在仓库根目录运行：

```sh
pnpm install --frozen-lockfile
pnpm check
pnpm --filter @avru/cli dev --help
pnpm build
pnpm dev:daemon
```

最后一条启动 `127.0.0.1:43821` 本机服务，并在终端给出本次启动的管理链接。打开该链接；请不要分享链接。重启后需重新打开新链接。Ctrl+C 停止。此为开发入口，不安装系统服务、不配置自启动，也不开放 MCP/OAuth。

开发扩展产物位于 `apps/extension/.output/chrome-mv3`。在受支持的 Chromium 测试浏览器扩展管理页启用开发者模式并加载该目录，然后打开 Avru 扩展弹窗，输入配置名称并点击“配对”。比较弹窗与管理页的六位核对码，在管理页批准。无需复制或填写内部凭据。其他浏览器配置重复该步骤。

管理页显示普通 HTTP/HTTPS 标签的标题和去掉查询参数/片段的地址；不采集无痕、浏览器系统或文件页面，不读取页面正文。关闭浏览器后显示离线，重新打开会使用内部凭据恢复连接。需要停止访问时，在管理页撤销该浏览器配对。扩展弹窗“断开并清除本地凭据”只清除扩展端，服务端登记需在管理页撤销。

daemon 默认使用当前 OS 用户的数据目录保存配对身份与凭据哈希（不保存标签）。可用 `AVRU_DATA_DIR` 指定专用开发目录；不要指向含其他应用数据的目录。`AVRU_PORT` 可调整开发端口，扩展弹窗需使用相同端口。`pnpm dev:web` 只用于界面开发；完整配对须使用 daemon 同源托管页面，而不是 Vite 的独立端口。

端到端开发检查需要浏览器：正常开发环境先 `pnpm exec playwright install chromium`，再 `pnpm test:e2e`。也可用 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` 指定现有测试 Chromium；此选项不改变产品接入用户浏览器的方案。实际端到端执行证据见本机连接记录；测试配置存在不等于通过。

```text
apps/cli         npx 生命周期入口（当前仅帮助/版本）
apps/daemon      本机可信配对、Web 托管与标签会话
apps/web         React 管理界面
apps/extension   WXT 浏览器扩展
packages/runner  独立 QuickJS WASM 进程边界，待实现
packages/protocol 跨组件消息合同边界，待实现
tests/e2e        跨组件/UI 验收
```

## 本地验证安装包

运行 `pnpm package:cli` 生成 `artifacts/avru`，`pnpm test:installer` 验证真实 daemon bundle 的安装/修复/缓存删除/卸载。正式 npm 包尚未发布。不要使用开发源码目录作为登录自启动位置。
